# Bikini Bottom Rebellion

Welcome to the official repository for **Bikini Bottom Rebellion** - the high-energy punk band bringing SpongeBob SquarePants to the mosh pit.

## About the Band

Bikini Bottom Rebellion is a punk powerhouse that exclusively covers songs from SpongeBob SquarePants, transforming beloved tracks like "F.U.N. Song" and "Sweet Victory" into raw, aggressive punk anthems. With shredding guitars, pounding drums, and gritty vocals, we're taking childhood nostalgia and cranking it up to 11.

## Band Members

- **Sallar** - Lead Vocals
- **Bryan K** - Guitar
- **Dan Gornstein** - Bass
- **Ryan Kendig** - Drums
